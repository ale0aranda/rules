# Examples

Copy the files you need into the root of your project and install the
corresponding peer dependency.

| File | Preset |
| --- | --- |
| `biome.example.json` | Biome |
| `commitlint.config.mjs` | Commitlint |
| `tsconfig.example.json` | TypeScript |
| `vitest.config.mjs` | Vitest |
| `playwright.config.mjs` | Playwright |
| `vite.config.mjs` | Vite + React |
| `next.config.mjs` | Next.js |
| `tsup.config.mjs` | tsup library |
| `renovate.example.json` | Renovate |

These examples intentionally contain only the shared configuration. Add
project-specific options through the helper's override object or by extending
the JSON preset.
